Conceptos de las Relaciones de Servicio

Oferta de Servicio (Service Offering)

Una descripción formal de uno o más servicios, diseñada para satisfacer las necesidades de un grupo de consumidores objetivo. Puede incluir bienes, acceso a recursos y acciones de servicio específicas.

Provisión de Servicio (Service Provision)

Las actividades realizadas por una organización proveedora para ofrecer servicios. Incluye la gestión de recursos, la configuración para satisfacer las necesidades del usuario, el cumplimiento de las tareas y el soporte.

Consumo de Servicio (Service Consumption)

Las actividades realizadas por un consumidor de servicios para utilizarlos. Esto abarca la gestión de los recursos del consumidor necesarios para usar el servicio y las acciones directas de uso.

Gestión de Relaciones de Servicio (Service Relationship Management)

Las actividades conjuntas realizadas por el proveedor y el consumidor para asegurar la cocreación continua de valor. Se basa en las ofertas de servicio acordadas y disponibles.
